==================================================
NEXORA PURPOSE
==================================================

NEXORA is a Smart AI-Enabled Rapid Feed and Silage Quality Testing System for Dairy Farmers.

The complete concept is:

Silage sample
→ Camera/Image
→ pH + Moisture + Temperature + VOC + NIR
→ ESP32/device layer
→ AI analysis
→ Silage quality score
→ Spoilage/deterioration risk
→ Farm-specific feeding/ration recommendation
→ Milk-quality decision support
→ Actual milk result
→ Feedback loop
→ Better future recommendations

The system should AUGMENT experienced farmers, not replace them.

Milk-quality prediction must ALWAYS be presented as decision support with uncertainty/confidence, NOT as a guaranteed causal improvement.
